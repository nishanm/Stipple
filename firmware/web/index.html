          Access

          Sent in the clear over your network, and stored on the device in the clear. It keeps the rest of the LAN out; it is not protection from someone holding the device. Forgotten it? Hold − and + together for five seconds and it is cleared.

          Firmware

          Checking…

          Upload libstipple.so from a release. It is checked here first — it has to be a 32-bit ARM shared library, so a host build is refused rather than installed — then written beside the running one and renamed into place, so a failed upload changes nothing. Nothing is flashed, and the device keeps the previous version so you can go back.

          Backup

          Downloads every setting as a file. The MQTT password is not in it — the device never gives it back, to anyone — so it has to be typed in again after a restore.

          Reset

          Puts settings back to their defaults. The device keeps its name, so it is still the one you were looking at.

          Restart

          Settings are saved as you change them, so a restart loses nothing.
